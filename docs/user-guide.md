# 用户手册

## 角色

- 管理员：节点、用户、模型状态和白名单配置。
- 运维员：查看事件、发起诊断、预览与审批动作。
- 只读用户：查看态势、事件、证据和评测报告。

## 事件处理

1. 在“态势总览”查看拓扑上的根因节点和传播方向。
2. 在“事件中心”选择事件，核对指标、日志或 Trace 证据 ID。
3. 若诊断置信度低或数据缺失，先补采证据，不直接审批修复。
4. 展开动作预览，核对目标节点、固定参数、风险、前置检查和回滚方式。
5. 审批后等待 Agent 回传退出码、标准输出、标准错误和健康检查。
6. 健康检查失败时按实验恢复脚本回滚，并保留执行与审计记录。

“智能问答”不会直接执行命令；“评测报告”只展示由盲测文件产生的指标。页面显示门槛不代表项目已达标。
