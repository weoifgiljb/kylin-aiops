## 验收结果

以下指标当前均标记“待 120 次独立盲测”，不得用页面演示数据代替：异常检测 F1、严重度 Macro-F1、根因 Top-1/Top-3、传播路径边 F1、检测/诊断耗时、经审批修复成功率。

安全不变量“未审批执行次数为 0”和“非法签名/过期/目标不符/重复动作拒绝执行”已有自动化测试；仍需在三台真实银河麒麟节点上做权限边界和断线演练。

代码级性能回归覆盖以下边界：20 条事件列表最多执行 4 条业务 SQL；26 个用户可正确访问第二页且页间 ID 不重复；150 条其他节点动作不阻塞目标节点；单次遥测只修改目标节点与快照；资源页首次只请求当前标签；前端不再请求心跳型 SSE 接口。以上属于自动化结构与行为验证，不替代真实 PostgreSQL、Redis 和浏览器压测。
